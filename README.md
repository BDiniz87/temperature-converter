# 🌡️ Temperature Converter

A clean, functional, and responsive two-way temperature converter built with vanilla HTML, CSS, and JavaScript.

🔗 **Live Demo:** [https://bdiniz87.github.io/temperature-converter/](https://bdiniz87.github.io/temperature-converter/)

---

## 🚀 Features

- **Real-Time Conversion:** Instant conversion between Celsius and Fahrenheit as you type.
- **Bi-Directional Calculation:** Input values in either field to get immediate results.
- **Responsive Layout:** Centered card interface designed for desktop and mobile browsers.
- **System Dark Mode Support:** Automatically adapts to the user's system theme preference.
- **Clean Input Formatting:** Clean user experience with external unit badges (`°C` / `°F`).

---

## 🛠️ Technologies Used

- **HTML5:** Semantic markup and structure.
- **CSS3:** Flexbox layout, media queries for Dark Mode, and custom styling.
- **JavaScript (ES6):** DOM manipulation and event handling (`input` event listeners).
